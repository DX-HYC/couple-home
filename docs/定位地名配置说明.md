# 定位地名自动识别 —— 配置说明

实时位置现在支持**自动显示地名**（如「南昌影视传播职业学院」），不再需要手动标注。

微信的 `wx.getLocation` 只返回经纬度，不返回文字地址，所以需要接入腾讯位置服务的
逆地理编码接口。坐标系与微信一致（gcj02），无需转换。

---

## 需要你做两步配置（约 5 分钟）

### 第一步：申请腾讯位置服务 key

1. 打开 https://lbs.qq.com ，用 QQ 或微信登录
2. 进入「应用管理」→「我的应用」→ 创建应用
3. 添加 key，**类型选择「WebServiceAPI」**（注意：不要选「微信小程序」类型，
   本项目的请求是 wx.request 直连，不是小程序地图组件）
4. 配额：个人默认每天 1 万次免费调用，足够情侣应用使用
5. 建议在该 key 的配置里开启「域名白名单」，填 `mp-api.app.workbuddy.host` 之外的
   调用方域名（实际请求域名是小程序侧，白名单可按需配置，不配也能用）

### 第二步：把 key 填进代码

打开 `utils/geo.js`，找到这一行：

```js
const LBS_KEY = ''
```

把引号里填上你的 key，例如：

```js
const LBS_KEY = 'OB4BZ-D4W3U-B7VVO-4PJWW-6TKDJ-WPB77'
```

### 第三步（重要）：配置 request 合法域名

小程序后台 → 「开发管理」→「开发设置」→「request 合法域名」→ 添加：

```
https://apis.map.qq.com
```

> 开发版 / 体验版可以在微信开发者工具的「详情 → 本地设置」里勾选
> 「不校验合法域名...」，跳过这一步直接测；**正式发布前必须配置**，否则真机上反查会失败。

## 效果

| 场景 | 表现 |
|---|---|
| 静止或小范围移动（40 米内） | 复用上次结果，不重复请求，地名不跳动 |
| 移动超过 40 米 | 自动重新反查，地名跟着更新 |
| 附近有学校/公司/小区 | 显示「POI 名称 · 详细地址」，如「南昌影视传播职业学院 · 江西省南昌市...」 |
| 反查失败 / key 未配置 | 优雅降级：显示「尚未识别地点」并提供手动标注入口，不会卡住或报错 |
| 对方查看 | 对方打开位置页时会自动识别并写入，你读到的就是地名 |

手动标注入口仍保留（「换个地点标注」按钮），作为反查失败时的兜底。

## 常见问题

**Q：没配置 key 会怎样？**
A：定位照常工作，只是地名显示为「尚未识别地点（坐标）」，并有手动标注兜底。
界面上会提示未配置 key，不会报错。

**Q：key 会泄露吗？**
A：key 会出现在小程序前端代码里（任何前端 key 都不可避免）。建议在腾讯位置服务
后台给 key 配置域名白名单限制滥用。对小众个人应用风险可控；如需彻底隐藏 key，
需要改为服务端代理（本项目暂无云函数通道）。

**Q：调用次数超了怎么办？**
A：免费额度是 1 万次/天。本项目已做 40 米移动阈值 + 60 秒刷新间隔的限流，
正常使用一天远不到 100 次。若超限，反查失败会自动降级到手动标注，不影响定位本身。

**Q：地名不准确？**
A：逆地理编码取的是 200 米内最近的 POI。在 POI 密集区域（如商业区）可能取到
相邻建筑。可点「换个地点标注」手动修正。
