# 天气功能域名配置（必须做，否则一定失败）

## 症状

天气卡片显示「网络不给力，天气没取到」或「天气域名未授权」。

## 原因

微信小程序规定：**所有 `wx.request` 请求的域名，必须提前在小程序后台登记**。
未登记的域名会被微信直接拦截，连请求都发不出去。

本项目使用的天气服务是 Open-Meteo（免费、无需 API key），
但它和你的小程序不在同一个域名下，所以必须单独登记。

## 解决方法（2 分钟）

### 1. 打开小程序后台

https://mp.weixin.qq.com

用**管理员**账号登录（普通开发者无权限改域名）。

### 2. 进入域名配置

左侧菜单：**开发管理 → 开发设置 → 服务器域名**

找到 **request 合法域名** 这一栏。

### 3. 添加域名

点击「修改」，在 `request 合法域名` 里追加一行：

```
https://api.open-meteo.com
```

注意事项：
- 必须带 `https://`，不能带端口号
- **只能添加域名，不能带路径**。写 `https://api.open-meteo.com/v1` 是无效的
- 一行一个，改完点「保存并提交」

### 4. 等待生效

保存后**立即生效**，无需审核。

但如果小程序已经发布过线上版本，可能需要重新上传代码才能让新配置对体验版/开发版生效。

### 5. 验证

改完后重新编译小程序，进首页看天气卡片。
如果显示温度和天气描述，就通了。

---

## 排错

| 现象 | 原因 |
|---|---|
| 提示「url not in domain list」 | 域名没加，或带了路径/端口 |
| 提示「不在以下 request 合法域名列表中」 | 同上 |
| 域名加了但还是失败 | 检查是否带了 `https://`，或域名拼写错误 |
| 开发版能用、真机预览不行 | 后台配置未同步，重新保存一次并重新编译 |
| 定位失败但天气也不显示 | 代码里已做兜底：定位失败用默认坐标，天气仍应显示 |

---

## 为什么选 Open-Meteo

| 对比项 | Open-Meteo | 和风天气 | 彩云天气 |
|---|---|---|---|
| 费用 | 免费 | 免费额度有限 | 免费额度有限 |
| API key | **不需要** | 需要注册 | 需要注册 |
| 域名配置 | 只需 1 个 | 需 1 个 | 需 1 个 |
| 数据源 | 各国气象局公开数据 | 商业数据 | 商业数据 |

选它的主要理由是**不需要 API key**——少一步注册，少一个可能泄露的凭证。

---

## 如果不想配域名

天气会一直显示错误提示，但**不影响小程序其它任何功能**。
天气卡片是独立的，失败时只显示一行提示，首页其它内容正常加载。
