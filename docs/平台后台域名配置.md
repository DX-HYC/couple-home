# 需要在平台后台添加的域名

## 背景

你的小程序（AppID `wxYOUR_APPID`）域名被 **WorkBuddy 平台托管**，
微信公众平台显示「服务器域名已托管给第三方，不能在此进行管理」。

所以域名不能去微信后台加，要去 **WorkBuddy 平台后台**加。

---

## 需要添加的域名清单

| 域名 | 用途 | 状态 |
|---|---|---|
| `https://mp-api.app.workbuddy.host` | 云数据库、登录、文件存储 | 应该已在（否则小程序跑不起来） |
| `https://api.open-meteo.com` | **天气接口（新增，必须加）** | ❌ 未加，导致天气失败 |

只有天气是新加的，`mp-api.app.workbuddy.host` 是平台自己的，应该已经配好了。

---

## 去哪里加

域名托管在平台侧，入口在 **WorkBuddy 平台后台**，不在微信后台。

按优先级试这几个位置：

### 位置 1：应用设置（最可能）

WorkBuddy 后台 → **头像 → 设置 → 数据管理 → 应用**
（资料库文档提到「发布后管理：依次点击头像 > 设置 > 数据管理，进入应用页签」）

在应用详情里找「服务器域名」「request 合法域名」或「域名白名单」类似的配置项。

### 位置 2：发布相关页面

WorkBuddy 后台 → 小程序发布 / 托管发布 相关页面，
看是否有「域名配置」「接口域名」选项。

### 位置 3：平台文档

https://www.workbuddy.cn/docs/workbuddy/Overview

搜「域名」「合法域名」「第三方托管」。

### 位置 4：找不到就找平台支持

如果以上都没有，说明该平台**不开放自定义域名添加**，
那天气功能无法实现（第三方 HTTP 接口必须有域名才能调）。

这种情况请告诉我，我把天气功能改成不依赖外部接口的形态（见下文备选方案）。

---

## 添加时的格式要求

- 必须带 `https://`
- **只填域名，不能带路径**。写 `https://api.open-meteo.com/v1` 是无效的
- 不能带端口号
- 一行一个

正确写法：
```
https://api.open-meteo.com
```

错误写法：
```
https://api.open-meteo.com/v1/forecast   ❌ 带了路径
api.open-meteo.com                        ❌ 没带协议
https://api.open-meteo.com:443            ❌ 带了端口
```

---

## 添加后验证

1. 保存配置
2. **重新编译小程序**（不是刷新，是重新编译）
3. 进首页看天气卡片
4. 如果显示温度和天气描述 → 成功

如果还是报错，把首页天气卡片显示的文字发我——
代码里现在区分了三种错误（域名未授权 / 超时 / 网络问题），能直接定位。

---

## 备选方案（如果平台不支持加域名）

我可以把天气改成**不调外部接口**的形态：

1. **完全去掉天气** —— 天气卡片改为显示「天气功能暂不可用」，其它功能不受影响
2. **手动输入** —— 用户自己填城市，显示固定文案（没实时数据，意义不大）
3. **等平台支持** —— 代码保留，域名配好那天自动就能用

我推荐 **3**：代码已经写好且测试通过，域名一旦配上立即生效，不需要再改任何代码。
